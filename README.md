### ECHO
**Evidence-Based Accessibility Assessment and Verification**

An accessibility auditing system focused on Arabic and Right-to-Left (RTL) websites.

ECHO combines rule-based detection and Case-Based Reasoning (CBR) to identify accessibility issues and investigate their impact on screen-reader output through NVDA verification.

**Technologies**

`Python` `Playwright` `Chrome` `NVDA` `PostgreSQL`
